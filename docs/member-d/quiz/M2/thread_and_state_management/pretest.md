题目：`AgentThread` 在 Agent Framework 中的作用是什么？
答案：`AgentThread` 是对话线程或对话状态的核心抽象，用于管理 Agent 的对话状态，抽象了不同 Agent 管理对话状态的不同方式。
题型：Open
用途：pretest
难度：foundation
评分方法：答出"对话线程/状态管理"得 1 分；答出"抽象不同管理方式"得 1 分；共 2 分。
资料名称：Semantic Kernel Agent Architecture
官方链接：https://learn.microsoft.com/nb-no/semantic-kernel/frameworks/agent/agent-architecture
出处章节：Agent Thread
是否更新MIRT：是
