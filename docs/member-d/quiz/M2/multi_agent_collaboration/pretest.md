题目：Semantic Kernel Agent Orchestration 中的 Sequential（顺序编排）和 Concurrent（并发编排）有什么区别？
答案：Sequential（顺序编排）按流水线方式组织 Agent，每个 Agent 依次处理任务，将输出传递给下一个 Agent，适合有明确先后依赖的工作流。Concurrent（并发编排）让多个 Agent 并行处理同一个任务，各自独立处理输入，结果被收集和汇总，适合需要多角度分析或头脑风暴的场景。
题型：Open
用途：pretest
难度：standard
评分方法：说明 Sequential“依次处理、有先后依赖”得 1 分；说明 Concurrent“并行处理、多角度汇总”得 1 分；共 2 分。
资料名称：Concurrent Agent Orchestration
官方链接：https://learn.microsoft.com/nb-no/semantic-kernel/frameworks/agent/agent-orchestration/concurrent
