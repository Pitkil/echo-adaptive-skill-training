题目：Semantic Kernel Agent Framework 中 `Agent` 类的核心作用是什么？
答案：`Agent` 是所有 Semantic Kernel Agent 的基类，是 Agent Framework 的核心抽象。一个 Agent 实例可以参与一个或多个对话，每个 Agent 必须定义其通信协议（`AgentChannel`）。
题型：Open
用途：pretest
难度：foundation
评分方法：答出"所有 Agent 的基类/核心抽象"得 1 分；答出"参与对话、定义通信协议"得 1 分；共 2 分。
资料名称：Semantic Kernel Agent Architecture
官方链接：https://learn.microsoft.com/nb-no/semantic-kernel/frameworks/agent/agent-architecture
出处章节：Agent
是否更新MIRT：是
