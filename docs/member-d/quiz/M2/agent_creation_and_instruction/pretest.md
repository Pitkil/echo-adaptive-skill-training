题目：Semantic Kernel Agent Framework 中 `Agent` 类的核心作用是什么？
答案：`Agent` 是 Agent Framework 的核心抽象，用来表示具有名称、指令和调用能力的智能体；具体 Agent 类型负责连接相应模型服务并处理对话。
题型：Open
用途：pretest
难度：foundation
评分方法：答出"核心抽象/智能体"得 1 分；答出名称或指令得 1 分；答出调用模型服务并处理对话得 1 分；共 3 分。
资料名称：Semantic Kernel Agent Architecture
官方链接：https://learn.microsoft.com/en-us/semantic-kernel/frameworks/agent/agent-architecture
出处章节：Agent
是否更新MIRT：是
