题目：Semantic Kernel 支持哪些类型的记忆存储后端？
答案：Semantic Kernel 支持多种记忆存储后端，包括内存存储（In-Memory）和向量数据库（如 Chroma、Azure Cognitive Search、Qdrant 等）。
题型：Open
用途：posttest
难度：standard
评分方法：答出"内存存储"得 1 分；答出至少一种向量数据库得 1 分；共 2 分。
资料名称：Memory in Semantic Kernel
官方链接：https://learn.microsoft.com/zh-cn/semantic-kernel/memories/
出处章节：全文
是否更新MIRT：是
