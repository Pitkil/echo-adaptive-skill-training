题目：Semantic Kernel 中记忆（Memory）机制的主要作用是什么？
答案：通过记忆，Agent 可以跨会话保留用户信息、历史对话内容和关键事实，实现长期状态保持和个性化交互。
题型：Open
用途：pretest
难度：foundation
评分方法：答出"跨会话保留信息"得 1 分；答出"长期状态保持/个性化"得 1 分；共 2 分。
资料名称：Memory in Semantic Kernel
官方链接：https://learn.microsoft.com/zh-cn/semantic-kernel/memories/
出处章节：全文
是否更新MIRT：是
