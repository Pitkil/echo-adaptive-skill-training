题目：Semantic Kernel Vector Store 在 Agent 检索场景中的主要作用是什么？
答案：Vector Store 用于保存带有文本、元数据和向量的记录，并根据查询向量或查询文本找回相关内容，供 Agent 回答或调用工具时使用。
题型：Open
用途：pretest
难度：foundation
评分方法：答出保存记录得 1 分；答出按相关性检索得 1 分；答出检索结果可供 Agent 使用得 1 分；共 3 分。
资料名称：What are Semantic Kernel Vector Stores?
官方链接：https://learn.microsoft.com/en-us/semantic-kernel/concepts/vector-store-connectors/
出处章节：Retrieval Augmented Generation、Vector Store Abstraction
是否更新MIRT：是
