题目：Semantic Kernel Process Framework 是什么？
答案：Process Framework 是 Semantic Kernel 中用于定义、序列化和执行多步骤 AI 工作流的方式，是一个有状态的、事件驱动的工作流引擎。
题型：Open
用途：pretest
难度：foundation
评分方法：答出"定义和执行多步骤工作流"得 1 分；答出"有状态、事件驱动"得 1 分；共 2 分。
资料名称：Overview of the Process Framework
官方链接：https://learn.microsoft.com/en-sg/semantic-kernel/frameworks/process/process-framework
出处章节：全文
是否更新MIRT：是
