题目：Python Semantic Kernel 为 Kernel 函数执行提供哪些核心时长指标？
答案：`semantic_kernel.function.invocation.duration` 用于记录普通函数调用时长，`semantic_kernel.function.streaming.duration` 用于记录流式函数执行时长。
题型：Open
用途：posttest
难度：standard
评分方法：每答对一个完整指标名称得 1 分，共 2 分。
资料名称：Observability in Semantic Kernel
官方链接：https://learn.microsoft.com/en-us/semantic-kernel/concepts/enterprise-readiness/observability/
出处章节：Metrics
是否更新MIRT：是
