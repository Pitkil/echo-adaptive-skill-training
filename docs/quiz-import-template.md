# 固定题库导入模板

上传前先在页面选择学习模块和知识点。文件中的每道题使用以下字段：题目、答案、
题型、用途、难度、评分方法、资料名称、官方链接、出处章节和是否更新 MIRT。
题目之间用 `---` 分隔。

题目：Kernel 在 Semantic Kernel 应用中的主要作用是什么？
答案：集中管理模型服务、插件和智能体运行所需的公共组件。
题型：Open
用途：前测
难度：基础
评分方法：说明模型服务和插件均由 Kernel 组织得 2 分；只说明其中一项得 1 分。
资料名称：Understanding the kernel in Semantic Kernel
官方链接：https://learn.microsoft.com/en-us/semantic-kernel/concepts/kernel
出处章节：The kernel is at the center
是否更新MIRT：是

题目：插件函数的输入和输出为什么需要清楚描述？
答案：清楚的描述能够帮助模型选择正确函数，并生成符合要求的调用参数。
题型：Open
用途：阶段测试
难度：标准
评分方法：说明函数选择和参数生成各得 1 分。
资料名称：Plugins in Semantic Kernel
官方链接：https://learn.microsoft.com/en-us/semantic-kernel/concepts/plugins/
出处章节：What is a Plugin
是否更新MIRT：否
