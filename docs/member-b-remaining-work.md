# 成员 B 收尾任务与验收清单

本文只列成员 B 在“微表征接入”职责内尚需补齐的交付。公共数据库迁移、公共导航、
学习者页面和最终系统集成仍由 A 负责。

## 已有基础，不要重复实现

- 已有微表征 HTTP 适配器、任务同步和轻量化联调服务。
- 已有学习者单段录音、讲师批量录音、授权检查、任务状态和重复提交保护。
- 已有时间定位、说话人确认、低可信过滤、个人事件与课次汇总的基础测试。
- 微表征只作为诊断与提示证据，不得判断专业答案或直接修改 U/A/R。

## 必须补齐的交付

### B1. 完成真实服务联调验收

Mock 继续用于 CI，但不能把 Mock 通过视为真实服务已经交付。至少使用现有真实微表征
服务完成一次学习者单段录音和一次讲师批量录音联调，并核对：

- 成功任务返回任务编号、状态和完成时间。
- 每条事件包含开始时间、结束时间、事件类型、可信度、简短文字和确认状态。
- 已绑定且已确认的说话人事件可以进入个人证据；未确认说话人的事件只进入课次统计。
- 未授权、格式不支持、文件损坏、超时和服务不可用时返回明确原因。
- 相同录音重复提交不重复分析，也不重复计入课次汇总。

联调记录写入 `docs/member-b/micro-integration-verification.md`。只保存脱敏后的请求摘要、
响应摘要和结论，不提交真实音频、身份信息、服务密钥或模型文件。

### B2. 计算识别效果

使用已有标注数据计算下列结果：

- 每类信号的样本数、TP、FP 和 FN。
- 每类信号的准确率或精确率、召回率和 F1。
- 总体微平均和宏平均结果。
- 使用的数据版本、阈值和计算日期。
- 至少三类常见误检、三类常见漏检及其可能原因。

建议新增可重复运行的 `scripts/evaluate_micro_representation.py`，输入为脱敏标注结果和检测
结果，输出 JSON 指标及失败明细。正式数据不进入 Git；仓库内只放最小匿名测试夹具。

评测结论写入 `docs/member-b/micro-evaluation-report.md`。报告不得只写一个总 F1，也不得
把 Mock 服务的固定输出当作识别效果。

### B3. 冻结 10 组差异案例

新增 `docs/member-b/micro_10_cases.json`，必须正好包含 10 个唯一 `case_id`。每组至少包含：

- `case_id`、`learner_type`、`module_id` 和场景说明。
- 单段或批量任务类型、授权状态、说话人状态和重复提交标识。
- 输入事件摘要、预期保留事件、预期过滤事件和课次汇总。
- 是否允许进入个人画像、交给 C 的证据以及交给 A 展示的内容。
- 预期降级原因或异常结果。

覆盖要求：

- P1、P2、P3 均至少出现 3 组。
- M1、M2、M3 均至少出现 3 组。
- 至少包含未授权、说话人未确认、低可信过滤、重复录音和服务不可用各 1 组。
- 至少包含 1 组前后课次变化，以及 1 组讲师批量录音。

### B4. 补齐验收测试

自动测试至少证明：

- 每条结果能回到原录音时间。
- 汇总包含各类信号次数、总停顿时间、前后变化和待确认数量。
- 只有已确认事件会作为个人证据交给 C。
- 未确认说话人的事件仍可进入匿名课次汇总。
- 重复提交不重复创建事件或增加汇总。
- 微表征处理前后，MIRT 的 U/A/R 不会因此改变。

## 提交建议

建议拆成三个可独立审核的 Commit：

1. `feat(micro): add reproducible recognition evaluation`
2. `test(micro): add ten frozen micro-representation cases`
3. `docs(micro): record real-service verification and metrics`

全部修改提交到 `member/b-micro-signal`，创建目标为 `main` 的 PR。PR 必须写清真实服务
是否完成联调、指标数据来源、未解决问题和回退方法。

## 完成判定

以下条件必须同时满足，B 才能标记完成：

- 真实服务完成单段和批量联调，失败场景有明确降级。
- 识别效果报告包含可复现的准确率或精确率、召回率、F1 和误检漏检说明。
- 10 组案例数量、编号和覆盖检查通过。
- B 相关测试以及项目完整质量门禁全部通过。
- PR 已由负责人审核并合并，且未提交音频、模型、密钥或真实个人信息。

## 不属于 B 的工作

- 不重新训练微表征模型。
- 不修改 MIRT 算法、题目判分或 Semantic Kernel 课程内容。
- 不负责公共数据库迁移、公共导航和最终页面接入。
