# 赛题要求映射

## 符合性判断

产品方向符合“领域知识个性化生成与多智能体协同决策系统”要求。竞争力来自五项组合：

- ECHO 的引导式对话与可持久化阶段状态
- U/A/R 三维 MIRT 能力估计
- 课堂微表征形成额外诊断证据
- SimpleMem 保留跨会话稳定误区与干预效果
- 基于多路召回与混合向量的可追溯 RAG 检索引擎与内容检查形成可追溯、低幻觉资源闭环

## 要求与交付

| 赛题要求 | 比赛交付 |
|---|---|
| 垂直领域技能培训 | 固定为基于 Microsoft Semantic Kernel 的企业级智能体应用开发 |
| 至少三个 Agent | 学习情况分析、内容生成、内容检查、下一步安排 |
| 学习者先验画像 | 模块级 U/A/R、知识盲区、记忆和已确认微表征 |
| 领域知识库 | 基于多路召回与混合向量的可追溯 RAG 检索引擎，支持入库、检索、重排、引用和版本记录 |
| 三类个性化资源 | 定制学习资料、实操指南、阶段测试 |
| 可视化报告 | 知识盲区、难度匹配曲线、个性化学习路径 |
| 动态迭代 | 作答更新 MIRT，反馈更新记忆，决策选择下一动作 |
| 交叉验证 | 内容生成 Agent 与内容检查 Agent 分离，失败局部重做 |
| 隐私合规 | 授权、说话人确认、权限过滤、审计与删除 |

专业内容仅取自 Microsoft Learn Semantic Kernel 文档和
`microsoft/semantic-kernel` 官方仓库及示例。基于多路召回与混合向量的可追溯 RAG 检索引擎是证据基础设施，不是培训领域。

## 竞争指标

- 至少三组差异化学习者画像
- 至少 50 组冻结端到端评测
- 幻觉率 `< 5%`
- 难度适配率 `>= 85%`
- 核心知识覆盖率 `>= 90%`
- 引用可追溯率目标 `100%`

## 必须真实演示

1. 学习者进入一个培训模块并完成前测或阶段题。
2. 诊断服务输出能力、知识盲区与证据置信度。
3. 基于多路召回与混合向量的可追溯 RAG 检索引擎返回可定位来源。
4. 内容生成 Agent 产生三类资源。
5. 内容检查 Agent 展示通过项、失败原因和重做结果。
6. 下一步安排 Agent 选择下一任务并保存原因。
7. 学习画像显示三种视图，服务异常时显示降级原因。

不增加独立专家端、评审端、研究者端和无数据闭环的装饰性 Agent。
